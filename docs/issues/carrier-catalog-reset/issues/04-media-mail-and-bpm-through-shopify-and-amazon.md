# Media Mail and Bound Printed Matter through Shopify and Amazon

Status: needs-triage

Repo: `polybag`

> *This was generated by AI during triage.*

## Parent

[PRD](../PRD.md), *Media Mail* and *Constraints from the sources*. ADR-0006 decisions 10
and 11.

## What to build

Media Mail's requirement binds every source, not only the direct USPS account. Amazon's
Bound Printed Matter is no longer dropped, because Amazon checks the order's products
for it.

- **Shopify.** Before `09`, Shopify's own `usps:MediaMail` catalog row carries the media
  requirement, and the seeder sets it.
  - `ShopifyAdapter::blindPurchaseOffers()` makes no Media Mail offer for a Package that
    does not qualify.
  - `resolveBlindOffer()` re-derives the offers at purchase, so a stale Media Mail offer
    is refused there too. So is a rule's pre-selected one.
- **Amazon, catalog identity.** The adapter sets `RateResponse::$carrierServiceId` and
  `$carrierId` on every offer, as `02` does for direct rates, and stores them on the
  Offer. The service id comes from the mapping it already loads, and is null when
  nobody has mapped the service. The carrier comes from Amazon's `carrierName` through
  `CarrierNormalizer`, mapped or not, so an unmapped offer still names its carrier. It
  is null only for a carrier with no row.
- **Amazon, Media Mail.**
  - Remove `USPS_PTP_MM` from `CONTENT_RESTRICTED_SERVICES`.
  - An Amazon offer whose mapped `CarrierService` requires media contents is dropped
    inside the adapter for a Package that does not qualify. The drop runs in
    `isBuyable()`, beside `fitsThePackaging()`, so no `ShippingOffer` is issued for it.
  - Until `11` seeds Amazon's known mappings, `USPS_PTP_MM` is also gated by its
    identifier, so an unmapped Media Mail offer is never shown for a Package that does
    not qualify. `11` removes that fallback.
  - Amazon's own product check still runs, so an offer shown has passed both checks.
- **Amazon, Bound Printed Matter.**
  - Stop dropping `USPS_PTP_BPM`. Every captured response refuses it for "The shipping
    service is not available for the products in the order."
  - **Show it, but never buy it unattended.** It carries no catalog service, and nothing
    in PolyBag vouches for the contents. Amazon's product classes do not match
    eligibility exactly. The rate is marked attended-only, and `RateSelector` withholds
    it whatever the approvals say, including an approval of everything. From `13` it
    also overrides the method's *any service*. The refusal names the content
    restriction.
  - Keep `UPS_PTP_SUREPOST_BPM` dropped for good. Ground Saver BPM is not authored, and
    nothing shows that Amazon checks products for it.
  - Keep `UPS_PTP_SUREPOST_MEDIA` dropped until `11` maps it to UPS Ground Saver Media,
    which carries the media requirement. PolyBag's own check guards it from then on, as
    it guards direct USPS Media Mail, so Amazon's check is not needed.
  - These identifiers are the one list the adapter keeps. Name it in the code as
    ADR-0006 decision 10's exception: Amazon identifiers with a known content
    restriction and no catalog service. After `11` it holds `UPS_PTP_SUREPOST_BPM`
    (dropped) and `USPS_PTP_BPM` (attended-only).
  - A dropped offer is still recorded as an observation.
- **Correct the record.** Append a dated comment to `amazon-buy-shipping/12`. It said the
  delivery promise had excluded Media Mail and BPM; the captures give a product reason.

## Acceptance criteria

- [ ] A Shopify order's Package that qualifies is offered the Shopify Media Mail blind
      offer. One that does not is not offered it, and a stale selection of it is refused
      at purchase
- [ ] An Amazon order's `USPS_PTP_MM` offer is shown for a qualifying Package. For one
      that does not qualify it is dropped, mapped or not, with no `ShippingOffer` row
- [ ] `USPS_PTP_BPM` offers appear on the Ship page, and automation withholds them even
      under an approval of everything, naming the content restriction
- [ ] `UPS_PTP_SUREPOST_MEDIA` and `UPS_PTP_SUREPOST_BPM` are still dropped, the first
      until `11` maps it
- [ ] Observations are still recorded for dropped offers
- [ ] Every Amazon offer carries its carrier id, including an unmapped OnTrac offer once
      `11` seeds OnTrac, and a mapped offer carries its `CarrierService` id
- [ ] `amazon-buy-shipping/12` carries the corrected evidence
