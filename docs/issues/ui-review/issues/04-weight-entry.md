# Manual Ship's scale overwrites a typed weight, and the customs weight dialog offers the wrong fix

> *This was generated by AI during the ui-review walk-through.*

Status: done

Source: [findings](../findings.md) M2, S9 (P8 noted)

Page or flow: Manual Ship weight field; Ship page "Customs Weight Mismatch" dialog

Severity: medium

Call: before the demo

## Problem

- **M2.** `resources/views/filament/pages/manual-ship.blade.php` sets
  `$wire.data.weight` on every scale reading above zero, so a typed weight snaps back while
  a scale is connected. Pack updates only when the reading changes.
- **S9.** The dialog says the item weight exceeds the package weight and offers **Override &
  Ship** (rewrite the customs weights) or Cancel. It shows neither weight, and the usual cause
  is a wrong scale reading.

## Fix

1. Manual Ship: copy Pack's rule (write the weight only when the reading changes).
2. Dialog: show both weights; primary action "Back to Pack to Reweigh", override secondary.

## Done when

A browser-free test of the Manual Ship script rule is impractical, so cover the dialog in a
Livewire test (both weights in the text, both actions present) and check M2 by hand with a
scale or the scale script stubbed.
