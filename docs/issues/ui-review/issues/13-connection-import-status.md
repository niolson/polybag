# Nothing shows whether a connection is importing

> *This was generated by AI during the ui-review walk-through.*

Status: ready-for-human

Source: [findings](../findings.md) CN1

Page or flow: Connections list and form

Severity: medium

Call: after the release-polish freeze. It needs an import-run record, which does not exist
(no model or table holds import history), so it is a feature.

## Problem

The list's Updated column is when the record was edited; the connection page has no import
section. "Is my store importing?" has no answer in the UI.

## Sketch

Record each run (connection, started, finished, result, new / updated / closed counts,
error); show the last run on the list and the last few on the connection page.
