## Problem

- **SH1.** The address panel's subtitle says "Not validated" whenever the validator returned
  no corrected address (`ShipmentResource.php`, the `validated_address1` check), right above
  Deliverability "Deliverable".

  instance using the sample validator, including the fake-carriers demo.

## Fix

1. Subtitle: "Showing the validated address" when one was returned; "Checked, no corrections"
   when checked without one; "Not checked yet" only when unchecked.
2. Label the fake validator "Sample validator".
