# Batch Ship: show how to start one, prompt to print, and notice a stalled batch

> *This was generated by AI during the ui-review walk-through.*

Status: ready-for-agent

Source: [findings](../findings.md) LB1, BS2, BS1; with LB2–LB4, BS3–BS5

Page or flow: Label Batches list, Batch Ship dialog, batch results page; demo step 4

Severity: medium

Call: before the demo

## Problem

- **LB1.** Label Batches is an empty page; a batch starts from a Batch Ship button that appears
  on the Shipments list only while rows are ticked.
- **BS2.** The dialog says "Buy and print"; printing is a separate **Print Labels (N)** click,
  with nothing prompting it, and **Reprint All (N)** shows before anything printed.
- **BS1.** With no queue worker, the batch said "Processing", N Pending, indefinitely.
- **LB2–LB4, BS3–BS5.** Two-row toolbar; four names for the feature; box list sorted as text;
  no cost preview; thin results page; void says nothing about Shopify.

## Fix

1. Empty state that says how to start a batch, with a button to the Shipments list's Open tab.
2. On completion, a "N labels ready to print" callout beside Print Labels; Reprint All only
   once something has printed; dialog text "Buy a label for each…, then print them from the
   batch page".
3. When a batch has made no progress for a minute, say it is waiting for the background
   worker.
4. The low items as listed in the findings; for the void, add the Shopify sentence when the
   Package was exported.

Tests for the empty state, the completion callout and button visibility, and the stalled
notice (a batch with no progress older than a minute).
