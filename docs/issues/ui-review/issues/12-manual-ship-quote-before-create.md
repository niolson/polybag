# Manual Ship creates the Shipment and Package before showing a price

> *This was generated by AI during the ui-review walk-through.*

Status: done

Source: [findings](../findings.md) M1

Page or flow: Manual Ship → Choose a Rate

Severity: medium

Call: before the first customer, not the demo (the demo can buy straight away)

## Problem

`ManualShip::ship()` creates the Shipment and Package, then redirects to the Ship page. A
packer who only wants a price, or backs out, leaves an open Shipment that then shows in the
Shipments list, the dashboard count, pick batches and the sidebar badge.

## Decided 2026-10-18

Create the Shipment right away, as a **draft**, and keep the Ship page built on a Package.
Offers are package-bound by design, so quoting from a bare form would need a second quoting
path. A draft is a new `ShipmentStatus::Draft` rather than a flag: nearly everything that
means "work to do" already filters on `status = Open` (about 39 places), so a draft drops out
of all of them without being touched, and a forgotten query simply does not see drafts. A
boolean would have to be excluded in each one, and each miss would leak a half-made order
into a count or list, which is the bug this fixes.

## Fix

1. Add `ShipmentStatus::Draft` (label "Draft", gray). Document it in `CONTEXT.md` as a
   Shipment not yet an order: created by Manual Ship so a rate can be shown, never counted,
   listed, picked or exported. It is separate from a **Package Draft**.
2. `ManualShip::ship()` creates the Shipment as `Draft`. A successful purchase moves it to
   `Shipped` through the existing workflow; it never becomes `Open`.
3. A scheduled command deletes drafts untouched for 24 hours, with their Package. Never a
   Shipment that has a purchased Label.
4. Audit the places that do not filter on status and exclude drafts from each:
   the Shipments list's All tab, the unmapped shipping references query, reports that count
   Shipments or Packages without a status, the PII purge, import and reconciliation
   look-ups, and any `Shipment` count shown on the dashboard or in a badge.
5. A draft is reachable by whoever created it from a Manual Ship page link, so the packer
   can go back and finish; no list shows it. A "Drafts" view is a possible later addition.

## Done when

Tests that a draft does not appear on the Shipments list (All tab included), the dashboard
counts, the sidebar badge, pick batches or the unmapped references count; that purchase moves
it to Shipped; that the cleanup deletes a 24-hour-old draft and keeps a younger one and one
with a Label; and that Manual Ship leaves no Open Shipment behind.
