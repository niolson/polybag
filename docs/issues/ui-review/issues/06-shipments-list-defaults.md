## Problem

- **SL1.** The list opens on **All** statuses, ten rows to a page.
- **SL2.** There is no city, state or country column, not even hidden.
- **SL3.** Deliver By is hidden by default.

## Fix

1. Default to the Open tab; 25 rows per page.
2. A Destination column: "City, ST" for the US, the country name abroad, "APO/FPO/DPO" kept as
   is. The Domestic / International / Military filter is a follow-up, not part of this.
3. Show Deliver By by default (after `01` fixes its date).

## Done when

A Livewire test asserts the default tab, the Destination column's text for a domestic, a
foreign and a military Shipment, and Deliver By visible by default.
