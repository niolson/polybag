# Volume: carrier grouping, location filter, weight, export, drill-downs

Status: done

> *This was generated by AI during the reports review.*

## Problem

`daily_shipping_stats` holds carrier, service, location and weight, and Volume groups only
by channel, shipping method or period. Its drill-down links filter Shipments by
`created_at`, the import date, while the report counts by ship date, and the channel and
method links drop the date range (`release-polish/33`). Nothing exports (`ui-review` R6).

## Fix

- Group by **Carrier** as well. Service waits for [`04`](04-client-in-the-shipping-rollup.md):
  the rollup's `service` is the name each source reported, which no Packages filter can
  match exactly, so a drill-down from it would not match the number clicked.
- A **Location** filter when there is more than one Location.
- An **Avg Weight** column from `total_weight`, and a **Share** column (packages as a
  share of the total in range).
- Drill-downs open the **Packages** list filtered by ship date over the same range, plus
  the row's channel, method or carrier. The Packages list gains Ship Date (replacing its
  UTC-day Shipped filter), Channel and Shipping Method filters for that.
- **Export CSV** of the rows shown.

## Done when

Tests for each grouping, the location filter, the drill-down URL and the export.
