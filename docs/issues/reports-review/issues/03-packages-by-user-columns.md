# Packages by User: one table, more columns, export

Status: done

> *This was generated by AI during the reports review.*

## Problem

The report gives one number per user. It groups by `users.name`, so two users who share a
name merge. The By User mode needs a separate dropdown and uses ISO week numbers with the
calendar year, so late December can read `2025-W01` (`release-polish/33`).

## Fix

- One table with a **Group by** of User, User × Day, User × Week or User × Month; weeks are
  named by their Monday, as in Volume.
- Group by user id.
- Columns: Packages, Orders (distinct Shipments), Items (package items' quantity), Days
  Active and Packages per Active Day (user rows only), Labels Voided (voided by that user in
  range).
- **Export CSV**.

## Done when

Tests for same-name users, each column, the period groupings and the export.
