# Voided Labels report

Status: done

> *This was generated by AI during the reports review.*

## Problem

A voided Label stays in `package_labels` as history, and nowhere lists them. Carriers
refund voided postage later, or only on request, so someone has to check the refunds
arrive.

## Fix

A report of Labels voided in the range: void date, order, tracking, carrier and service,
postage source, cost, who voided it and why, and whether the Package was bought again.
Totals for count and cost. Filters for carrier and postage source. **Export CSV**.

## Done when

Tests for the range, totals and filters, and that an active Label is never listed.
