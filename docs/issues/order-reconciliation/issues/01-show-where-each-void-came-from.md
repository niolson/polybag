# Show where each void came from

Status: ready-for-agent
Category: enhancement
Repo: `polybag`

> *This was generated by AI during triage.*

## Parent

[PRD](../PRD.md), slice 1. Small; also fits `release-polish`.

## Problem

`PackageLabel.void_reason` records who voided a Label: `Operator`, `VoidedUpstream`
(voided at the source, such as the Shopify admin) or `Recorded`. Only View Package shows
it. On the Packages list and the Shipment view, a Package voided in the Shopify admin
looks the same as one an operator voided here, so nobody notices Labels being voided
outside PolyBag.

## Desired behavior

- The Packages list shows, for a Package whose most recent Label was voided, who voided
  it, with a filter on it.
- The Shipment view's Packages section shows the same.
- Wording comes from `VoidReason`'s label, so the three places agree.

## Acceptance criteria

- [ ] Packages list column and filter for the latest voided Label's `void_reason`
- [ ] Shipment view shows it per Package
- [ ] Feature tests for each `VoidReason` value on both pages
