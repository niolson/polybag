# Tidy the default box sizes

Status: needs-triage
Category: enhancement
Created: 2026-09-29

## Problem

The optional starter set of Box Sizes (Setup Wizard toggle, `BoxSizeSeeder`) is the first
thing a new install scans against, and it reads inconsistently on the Print Box Size
Barcodes sheet:

- Names and stored dimensions disagree in order: the box named `10x8x8` is stored as
  8 × 8 × 10, and `11x7x6` as 6 × 7 × 11. Neither order is wrong for rating, but a packer
  reads the name.
- The sheet's print order follows neither code nor size.

Every warehouse will keep its own set; this is only about the defaults being a clean
starting point.

## Questions

- Which dimension order does the product use everywhere (L × W × H with L ≥ W ≥ H)? The
  name, the form and the sheet should agree.
- Should the sheet sort by alias, by size, or let the operator choose?
- Are the stock sizes the most common ones for small sellers, and should any be dropped
  or added? `packaging-form-and-carrier-identity/06` already added the flat-rate
  packagings.
