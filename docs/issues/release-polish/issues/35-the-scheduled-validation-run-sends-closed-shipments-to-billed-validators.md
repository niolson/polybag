## Problem

The due query (`app/Console/Commands/ValidateShipmentsCommand.php:34-37`) has no status filter, and it never had one. Since `09` dropped the US-only filter, it also reaches international Shipments. A shipped or cancelled Shipment that was never settled is sent to USPS or Google. Examples: one closed by its source before the five-minute run, one whose address a manager edited after shipping, or one whose validators were all unavailable until it shipped. `PurgePiiCommand::purge()` (`app/Console/Commands/PurgePiiCommand.php:152`) nulls the address with a query-builder update, which leaves `checked` and the attempt alone. A purged Shipment that was still due is then sent to a paid validator with an empty street and city.

**Scenario.** Create a US Shipment with `checked = false`, no attempt and status `cancelled`. Run `shipments:validate`, and a USPS request goes out.

## What to build

Select only `status = open` in the due query and in `warnAboutCappedShipments()`.
