## Problem

`resources/views/pack-slips/slips.blade.php` lines 160, 173 and 199 render
`{{ city }}, {{ state_or_province }} {{ postal_code }}` for the client return address,
the default Location fallback and the ship-to. With a null state — allowed on Shipments,
client return addresses and, since #331, Locations — a London Location prints
`London,  E1 6AN`. None of the three blocks prints the country, so an international
order's slip shows a Polish address with no `Poland`.

## What to build

Join city, state and postal code with only the parts that are
present, and add the country name when it differs from the Location's country.
