Page or flow: Settings (`/settings`), first tab

Severity: medium — the help text is wrong for who can create batches, and a setting changes without saying so

Verified: observed in the browser on 2026-11-17, configuration C

## Problem

1. **PolyBag Prints Pick Batches** says "When enabled, pickers can create pick batches and print picking summaries before packing." There is no picker role. Only Managers and Admins can create batches (see 53).
2. With **Require Picking Before Shipping** on, turn **PolyBag Prints Pick Batches** off and save. Nothing is blocked afterwards (an unpicked Shipment opens on Scan & Pack), as expected. But the database now has `require_picking_before_shipping = 0`: it was cleared. Turning pick batches back on shows Require Picking switched off, and the page does not say it was reset. Someone who briefly turns picking off to test will find shipments no longer gated.

Screenshot: `.scratch/release-polish/picking-pack-slips/C-7-picking-back-on.png`

## What to build

Reword the helper text to name the real roles. Either keep the requirement's value while it is hidden, or say on the toggle that turning pick batches off also turns the requirement off.
