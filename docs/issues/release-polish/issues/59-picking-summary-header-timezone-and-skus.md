# The picking summary header says "3 SKUS" and shows a time in a different timezone from the rest of the app

> *This was generated by AI during release-polish pass 1.*

Status: done

Pass: 1 — picking and pack-slip walk-through

Page or flow: Picking Summary (`/pick-batches/{id}/summary`)

Severity: low — cosmetic

Verified: observed in the browser on 2026-11-17, configuration B

## Problem

The header reads "Nov 17, 2026 6:56 PM · 3 orders · 3 SKUS". Two things: "SKUS" should be "SKUs", and 6:56 PM is UTC, while the Pick Batches list shows the same batch as created "Nov 17, 2026 1:56 PM" (the user's timezone). The Bin column is "—" on every line. The **Bin Column** toggle in Settings (`pick_summary_show_bin`) defaults to on, but bins are rarely populated (Shopify has no bin data in the stable API; `InventoryBin` is only in the unstable one), so a new install prints an empty column.

Screenshot: `.scratch/release-polish/picking-pack-slips/B-2-picking-summary.png`

## What to build

Format the header time in the user's (or Location's) timezone and fix "SKUS". Default `pick_summary_show_bin` to off, or hide the column when no line in the batch has a bin.
