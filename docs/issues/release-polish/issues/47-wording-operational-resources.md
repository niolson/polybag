### A label void is announced as a shipment being cancelled

- Severity: high. Void is on the demo path (step 5). The success toast reads "Label voided" over a body saying a *shipment* was *cancelled*. A Shipment is the order, and a void does not cancel it. On the fake-carrier fallback instance, every void says this.
- Page or flow: Packages list → Void Label; View Package → Void Label. The Ship page void reaches the same messages.
- Locations:
  - `app/Services/Carriers/FedexAdapter.php` (readCancelReply) — "FedEx shipment cancelled." → "FedEx voided the label."
  - `app/Services/Carriers/FakeCarrierAdapter.php:265` — "Fake {carrier} shipment {tracking} cancelled" → "Sample {carrier} label {tracking} voided."
  - `app/Services/PostageSources/AmazonPostageSource.php:132` — "Amazon cancelled the shipment." → "Amazon voided the label."
  - `app/Services/Carriers/UpsAdapter.php` (readCancelReply) — fallback "UPS shipment voided." → "UPS voided the label."

**Why.** `CONTEXT.md`: Labels are voided and Shipments are cancelled, and a Shipment and a Label are distinct things.
