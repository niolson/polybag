# The pick batch Shipments table shows no picked status, so a picker cannot tell what is done

Pass: 1 — picking and pack-slip walk-through

Page or flow: View Pick Batch (`/pick-batches/{id}`)

Severity: medium — the picking step has no visible progress

Verified: observed in the browser on 2026-11-17, configuration B

## Problem

The Shipments table has the columns Tote, Reference, Name and City, and a **Mark Picked** button per row. After clicking **Mark Picked** on T01, its button simply disappears: no "Picked" label, no column, no confirmation I could see. Rows still to do and rows done differ only by a missing button. **Mark All Picked** completes the batch and its screenshot shows no summary of what was picked either.

Screenshot: `.scratch/release-polish/picking-pack-slips/B-6-after-mark-picked.png`

## What to build

Add a Picked column (or badge) to the table, and confirm each Mark Picked with a notification.
