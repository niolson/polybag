# A Packer cannot move an unpicked Shipment forward when picking is required, because only Managers can make a pick batch

> *This was generated by AI during release-polish pass 1.*

Status: done — 2026-11-17

Pass: 1 — picking and pack-slip walk-through

Page or flow: Scan & Pack (`/pack/{id}`), Generate Pick Batch (`/generate-pick-batch`), Pick Batches (`/pick-batches`), Print Pack Slips (`/print-pack-slips`)

Severity: high — with picking required, a Packer reaches a step they cannot complete or get unblocked from

Verified: observed in the browser on 2026-11-17, configuration C, signed in as `user` (Packer)

## Problem

1. Turn on **PolyBag Prints Pick Batches** and **Require Picking Before Shipping**.
2. Signed in as a Packer, open `/pack/3574`, an unpicked Shipment. It returns to `/pack` with the notification "Picking Required — Shipment D0AO7O0003 has not been picked yet."
3. Open `/generate-pick-batch` and `/pick-batches` directly: both answer `403 Forbidden`. `GeneratePickBatch::canAccess()` and `PickBatchResource::canAccess()` both require Manager or above, so the Packer has no sidebar link either.
4. Open Print Pack Slips: it says "Pack slips print from pick batches" and lists nothing, so a Packer cannot print slips either.

A Packer can neither pick, nor create the batch that would get a Shipment picked, nor print a slip, and nothing on screen says who can. The only way out is to find a Manager. On a small floor where Packers also pick, the workflow is stuck until a Manager makes every batch.

Screenshot: `.scratch/release-polish/picking-pack-slips/C-6-packer-refusal.png`

## What to build

Decide whether Packers may generate pick batches (the maintainer is leaning yes: it is needed sometimes). If so, allow Packer on Generate Pick Batch and Pick Batches (view, mark picked), and keep cancel/other destructive actions Manager-only if wanted. If not, the refusal must tell a Packer to ask a Manager for a pick batch.

## Comments

- 2026-11-17: decided yes, and built. Packers can open Pick Batches and Generate Pick
  Batch, use the Shipments table's Create Pick Batch, open a batch's picking summary and
  pack slips, and mark Shipments or a whole batch picked. Cancel Batch stays Manager-only.
  The `manager` route middleware had no other users and is removed. No ADR or earlier
  document gave a reason for the Manager gate; it came with the feature in `04ffc2d0`.
  Recorded in `warehouse-permissions/01`'s matrix. Covered by
  `tests/Feature/PackerPickBatchAccessTest.php`.
