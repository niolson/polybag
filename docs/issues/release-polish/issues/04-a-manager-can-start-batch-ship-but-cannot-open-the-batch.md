# A Manager can start Batch Ship but cannot open the batch it created

Page or flow: Shipments → Batch Ship → the batch view (demo step 4)

## Problem

The Batch Ship bulk action is visible to Manager and above
(`app/Filament/Resources/ShipmentResource.php:518`). On submit, it creates the batch, buys
the labels, and redirects to `LabelBatchResource`'s view page (`ShipmentResource.php:580`).
But that page is Admin-only, and so are the other ways to reach the batch:

- `LabelBatchResource` itself (`app/Filament/Resources/LabelBatchResource.php:38-42`)
- the old `BatchShipResults` redirect (`app/Filament/Pages/BatchShipResults.php:20-23`)
- the link in the `BatchLabelCompleted` notification
  (`app/Notifications/BatchLabelCompleted.php:53`)

So a Manager's labels are bought, and then the page that prints them and lists the failures
refuses the Manager.

Who may batch purchase at all is still open: `warehouse-permissions/01` marks it
"Undecided". Whichever way that goes, the action and its results page need to agree.

Either open `LabelBatchResource` and `BatchShipResults` to Managers, to match the action, or
raise the action to Admin. That is a product decision, which is why this issue is
`needs-triage`. Opening the batch pages to Managers matches what Managers can already do.
