# UPS gets a ship-to name or attention name longer than the 35 characters its schema allows

> *This was generated by AI during release-polish pass 4.*

Status: ready-for-agent

Pass: 4 — bug (review of label address characters and Locations outside the Americas)

Page or flow: Ship page purchase and batch ship, UPS

Severity: medium — a recipient with a long full name (or a long company name standing in as attention name) can have the label refused at Ship or in batch ship; nothing is truncated

Verified: confirmed (against UPS's own vendored CreateShipment schema; the live response to an over-long name was not checked). Line numbers are at `12592f33`; this area is unchanged on `dfd842c5`.

## Problem

`UpsAdapter::createShipment()` (`app/Services/Carriers/UpsAdapter.php`,
the `Shipper`, `ShipTo` and `ShipFrom` blocks around line 710) sends
`trim(firstName.' '.lastName)` and `buildAttentionName()` (line ~1522) with no length
limit, and `buildCustomsDetail()` does the same for `Contacts.SoldTo.Name` /
`AttentionName`. The schema caps each at 35. The only UPS fields cut to length are the
commodity description (line 1600), the vendor collect ID and the ultimate consignee's
company name (line 1969), which shows the limit was known for that one block. FedEx and
USPS cut their name fields (`UspsAdapter::addNameFields()` to 30/38); FedEx
`personName`, `companyName` and `city` are not cut either, but FedEx's documented limits
for those (70/35/35) were not checked against a schema, since the FedEx schema in
`tests/Fixtures/Schemas/fedexShip.json` is hand-written and carries no lengths.

Address lines are also sent uncut (`buildAddressLines()`), but the vendored schema puts
`maxLength` on the `AddressLine` array, where the validator does not apply it, so the
probe does not see that one. UPS documents 35 per line.

## Evidence

`tests/Feature/Probes/LabelCharacters/LabelFieldLengthTest.php`:

```php
<?php

use App\DataTransferObjects\Shipping\AddressData;
use App\DataTransferObjects\Shipping\PackageData;
use App\DataTransferObjects\Shipping\RateResponse;
use App\DataTransferObjects\Shipping\ShipRequest;
use App\Http\Integrations\Ups\Requests\CreateShipment;
use App\Services\Carriers\UpsAdapter;
use Saloon\Http\Faking\MockResponse;
use Saloon\Laravel\Facades\Saloon;

it('sends UPS a ship-to that fits the CreateShipment schema when the name and street are long', function (): void {
    createUpsAccount();
    Saloon::fake([
        '*oauth*' => MockResponse::make(['access_token' => 't', 'token_type' => 'Bearer', 'expires_in' => 3600]),
        CreateShipment::class => MockResponse::make(['ShipmentResponse' => ['ShipmentResults' => [
            'ShipmentIdentificationNumber' => '1Z9999999999999999',
            'ShipmentCharges' => ['TotalCharges' => ['MonetaryValue' => '11.00']],
            'PackageResults' => ['TrackingNumber' => '1Z9999999999999999', 'ShippingLabel' => ['GraphicImage' => 'R0lGODlhAQABAAAAACw=']],
        ]]]),
    ]);

    $request = new ShipRequest(
        fromAddress: new AddressData('Shipping', 'Center', '123 Warehouse St', 'Seattle', 'WA', '98072'),
        toAddress: new AddressData(
            firstName: 'Maria Fernanda de los Angeles',
            lastName: 'Gutierrez-Montenegro',
            streetAddress: '4500 North Saint Clair Shores Boulevard Apt 12',
            city: 'Rancho Santa Margarita Heights',
            stateOrProvince: 'CA',
            postalCode: '92688',
        ),
        packageData: new PackageData(weight: 2.0, length: 10, width: 8, height: 4),
        selectedRate: new RateResponse(carrier: 'UPS', serviceCode: '03', serviceName: 'UPS Ground', price: 11.00, metadata: ['serviceCode' => '03']),
    );

    (new UpsAdapter)->createShipment($request);

    Saloon::assertSent(function ($sent): bool {
        if (! $sent instanceof CreateShipment) {
            return false;
        }
        assertMatchesUpsSchema($sent->body()->all(), 'SHIPRequestWrapper', 'upsShipping');

        return true;
    });
});
```

```
Request body does not conform to upsShipping#/components/schemas/SHIPRequestWrapper:
  - ShipmentRequest.Shipment.ShipTo.Name: Must be at most 35 characters long
  - ShipmentRequest.Shipment.ShipTo.AttentionName: Must be at most 35 characters long
```

## What to build

Cut every UPS free-text field to its documented length with
`mb_substr()`: Name, AttentionName and CompanyDisplayableName 35, AddressLine 35 each,
City 30, on Shipper, ShipTo, ShipFrom and SoldTo. Where a street line is longer than 35,
see the next finding before choosing to cut rather than wrap. Add the same limits to
FedEx `personName`/`companyName`/`city` once checked against FedEx's documentation.
