# The Ship page shows "Custom" for every Package, whatever box was scanned at Pack

> *This was generated by AI during release-polish pass 4.*

Status: ready-for-agent

Pass: 4 — bug (review of the Pack page and box sizes)

Page or flow: Pack → Ship, the Package summary

Severity: medium — wrong on the demo path (Ship, step 3), right after the box was scanned on Pack

Verified: confirmed. Line numbers are at `12592f33`; this area is unchanged on `7649fe0c`.

## Problem

`resources/views/filament/pages/ship.blade.php:75` renders
`{{ $package->boxSize?->name ?? 'Custom' }}`. `BoxSize` has no `name` attribute (it is
`label`, `app/Models/BoxSize.php`), so the expression is always null and the Box field
always reads "Custom", even for a Package with a seeded or carrier box. A prospect watches
a box scanned at Pack and sees "Custom" on the next page. Present since the page was
written; no earlier pass filed it.

## Evidence

`tests/Feature/Probes/PackScanBoxes/ShipShowsPackedBoxTest.php`:

```php
<?php

use App\Enums\PackageStatus;

use App\Filament\Pages\Ship;
use App\Models\BoxSize;
use App\Models\Package;
use App\Models\Shipment;
use App\Models\User;
use Livewire\Livewire;

it('names the box scanned at Pack on the Ship page', function (): void {
    $this->actingAs(User::factory()->create(['role' => Role::Admin]));

    $boxSize = BoxSize::factory()->create(['label' => '10x8x6']);
    $package = Package::create([
        'shipment_id' => Shipment::factory()->create(['shipping_method_id' => null])->id,
        'box_size_id' => $boxSize->id,
        'weight' => 2.0, 'height' => 6, 'width' => 8, 'length' => 10,
        'status' => PackageStatus::Unshipped,
    ]);

    Livewire::test(Ship::class, ['package_id' => $package->id])
        ->assertDontSeeHtml('<dd class="mt-1">Custom</dd>')
        ->assertSeeHtml('<dd class="mt-1">10x8x6</dd>');
});
```
