# The VOID and REPRINT scan commands act on an earlier Label after a purchase on the Ship page

> *This was generated by AI during release-polish pass 4.*

Status: ready-for-agent

Pass: 4 — bug (review of the label lifecycle)

Page or flow: Pack → Ship page purchase → back to Pack, then `%CVOID` or `%CREPRINT` (demo
step 5)

Severity: high — a packer voids the Label of a parcel already handed over, and the Label
they meant to void stays live and billed.

Verified: confirmed. The test below fails at `12592f33`, and this code is unchanged on
`7649fe0c`.

## Problem

ADR-0007 decision 4 says `%CREPRINT` and `%CVOID` act on "the Label this browser session last
bought". Three purchase paths call `SessionLastLabel::remember()`:

- Pack's auto-ship (`app/Filament/Pages/Pack.php:469`)
- Manual Ship (`ManualShip.php:295`)
- View Package (`ViewPackage.php:264`)

The Ship page does not (`app/Filament/Pages/Ship.php:517`–`637`), and neither does
`EloquentPackageShippingWorkflow`. Yet Pack sends every Package that needs attended selection
to `/ship/{id}`, and the Ship page returns to `/pack` after the print.

So after Package A is auto-shipped and Package B is bought on the Ship page, the session
still remembers A's Label. Say B's label jams and the packer scans `%CVOID`.
`Pack::cancelLastLabel()` (`Pack.php:733`) then voids A's Label at the carrier and un-ships
A, whose parcel is already on the truck. B stays shipped. `%CREPRINT` prints A's label for
B's box.

If no Label was bought at Pack this session, both commands say "No label has been bought in
this session" right after a purchase.

## What to build

Remember the Label wherever a purchase completes for the person at the station, not page by
page:

- Call `SessionLastLabel::remember()` from the Ship page's successful `ship()`.
- Consider moving the call into the shipping workflow's attended `ship()` result, so a future
  page cannot miss it. Batch ship should not set it.

Keep the test above as the regression test. Pass 5's browser test of pack → ship → reprint →
void → buy again → reprint should go through the Ship page, not auto-ship.
