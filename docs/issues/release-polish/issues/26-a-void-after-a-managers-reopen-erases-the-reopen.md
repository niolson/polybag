## Problem

Decision 7 protects an `Open` Shipment with `status_origin = manager`. A
manager reopens an order the source cancelled, a packer buys a Label (`polybag`) and voids
it, and `Shipment::reopen()` (via `updateShippedStatus()`) sets the origin to null. The
Shipment is now an ordinary candidate, and the next import closes it `Cancelled` again, so
the packer cannot buy the replacement Label until a manager reopens it a second time.

## Evidence

Scenario: S `Cancelled`/`source` → manager sets `Open` (`manager`) → Label
bought (`Shipped`/`polybag`) → Label voided (`Open`, origin null) → next Shopify or Amazon
import looks S up, the source still reports it cancelled, `SourceClosureApplier` closes it.

## What to build

`reopen()` restores the origin the Shipment had before PolyBag shipped
it when that was `manager` (or keeps `manager` on any Shipment a manager reopened until a
manager changes it again).
