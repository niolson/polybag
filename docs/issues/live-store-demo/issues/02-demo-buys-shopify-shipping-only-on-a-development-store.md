# Demo buys Shopify Shipping only on a development store

Status: ready-for-agent
Category: bug
Repo: `polybag`

> *This was generated by AI during triage.*

## Parent

[PRD](../PRD.md), decision 2.

## Problem

Shopify Shipping has no sandbox. In Demo, a blind purchase on a connected live store
buys a real label and charges the merchant. The carrier sandbox that makes direct
postage harmless does not reach it.

## Desired behavior

- In Demo, a Shopify connection offers Shopify Shipping only when the store is a
  development store. Otherwise the blind purchase is not offered, on the Ship page or in
  batch or auto-ship. The Ship page says why ("Shopify Shipping is not available in demo
  mode on a live store"), instead of the option silently missing.
- A development store is one whose Admin GraphQL `shop.plan` reports
  `partnerDevelopment: true`, or `publicDisplayName: "Development"`:

  ```graphql
  { shop { plan { partnerDevelopment publicDisplayName } } }
  ```

- Read it live at purchase time, as the source of truth, and cache it briefly (minutes)
  per connection so rating does not add a round trip per request. Do not store it as a
  flag on the connection.
- If the plan cannot be read, treat the store as live.
- The guard is checked where the purchase is authorized, not only where the offer is
  shown, so a stale Ship page cannot buy.
- On the Shopify connection's edit page in Demo, show whether the store is a
  development store, and that Shopify Shipping is off when it is not.

## First step

Query our own development store, and confirm which of the two fields reports it. Stores
created from the Dev Dashboard, rather than a Partner organization, may differ. Record the
answer in Comments, in general terms: no store domain.

## Notes

- Production and Dev are unchanged.
- Check the scopes the connection already holds are enough to read `shop.plan`.
- `01` uses the same check for exports and fulfillment cancels, so build it as its own
  small service, not inside the purchase path. A live store's labels are blocked here,
  its exports there.
