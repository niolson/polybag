# Creating a FedEx account opens the Connect FedEx wizard

Status: ready-for-agent
Category: enhancement
Repo: `polybag`

> *This was generated by AI during triage.*

## Parent

[PRD](../PRD.md), decision 4.

## Problem

FedEx has no OAuth redirect. Its registration is the multi-step "Connect FedEx Account"
wizard (`HasFedexRegistration::fedexRegisterAction()`: EULA, account and address, then
MFA), through the broker's proxy connector when one is configured
(`FedexRegistrationService::getConnector()`). It is a header action on
`EditCarrierAccount` only. A new FedEx account is saved, and the operator then has to
find the action.

## Desired behavior

- After creating a FedEx account, redirect to its edit page with `?action=fedex_register`.
  Filament mounts a page action named in the `action` query parameter
  (`InteractsWithActions::$defaultAction` is `#[Url(as: 'action')]`), so the wizard opens
  on arrival.
- The Create button reads "Create & connect FedEx".
- Do this only when the broker is configured. The wizard drives FedEx's Account
  Registration API, which provisions child credentials under a parent CSP (Compatible
  Solution Provider) key. Ordinary developer API keys cannot authorize it, and
  `docs/self-hosting.md` tells a self-hoster to skip the wizard. Direct credentials
  already rate, label, track and close out on their own. So an account with its own API
  key and secret, and no broker, goes to the edit page as today. Opening the wizard for
  a self-hosted CSP parent key would need an explicit setting saying that is what the
  key is. That is out of scope until someone has one.
- "Create & create another" does not redirect.

## Notes

- The wizard sets `child_env` from the shared sandbox setting. In Demo that is always
  sandbox, which is what `02` expects when it hides the production fields there.
- The wizard cannot be dismissed by clicking away or Escape. Check that closing it with
  its own controls leaves the operator on a usable edit page, and that reloading the URL
  does not reopen it unexpectedly. If it does, drop the query parameter once mounted.

## Acceptance

- [ ] Creating a FedEx account with the broker configured redirects to
      `carrier-accounts.edit` with `action=fedex_register`, and the action is mounted
- [ ] Without the broker, create goes to the edit page with no action, whether or not
      the account's own API key and secret were entered
