# UPS rate request omits dimensions and the residential indicator

Status: needs-triage
Category: bug
Repo: `polybag`

> *This was generated by AI during triage.*

## Parent

[PRD](../PRD.md). Found by `postage-source-split/18`'s production probe.

## Problem

A UPS Ground label quoted at $16.96 billed $39.13. Two of the four lines on the
receipt are things the rate request never described:

- **Dimensional weight.** The rate request sends `PackageWeight` and no `Dimensions`,
  so UPS rates the actual weight (0.15 lb → 1 lb minimum). The ship request sends the
  box, so the label is billed at the 2 lb dimensional weight: $17.40 transportation
  plus $8.68 fuel against a $16.96 quote in total.
- **Residential.** `ResidentialAddressIndicator` is sent only when
  `RateRequest::$residential` is true, which is set from address validation. When the
  address has not been classified — or was classified commercial by a validator that
  UPS disagrees with — the quote has no residential surcharge ($6.50) and the label
  does. The delivery-area surcharge ($6.55) is likewise keyed on UPS's own view of the
  address.

The packer chooses a rate by price. A quote that is 43% of the bill defeats the
comparison, and a rate-shopping rule that picks "cheapest" picks UPS on a number UPS
will not honour.

## Desired behaviour

The rate request describes the package the way the ship request does: `Dimensions`
whenever the package has them (UPS documents them as not applicable to a Letter, the
same carve-out the ship request already makes). For residential, either send the
indicator from what the app knows and let UPS's own classification apply on the label
— the current behaviour, which needs the validator to be right — or ask UPS to
classify by omitting it and reading the `RatedShipment` for the surcharge it applied.
Which of those is the maintainer's call; the dimensions half is not.

`upsRating.json` is vendored, so the added fields are schema-checked in the existing
`UpsAdapterTest` closures.

## Reproduce

CIE quotes $16.96 and ships at $39.13 for package 209 with `sandbox_mode` on;
`.scratch/ups-label-recovery/probe-18-label-recovery.php` does both in one run and
buys nothing real.

## Recommendation

`ready-for-agent` for the dimensions half once triaged; the residential half needs the
decision above.
