# Fill a Product's customs value from the store's price

Status: needs-triage
Category: enhancement
Repo: `polybag`

> *This was generated by AI during triage.*

## Parent

`manual-ship-contents`. Split from `01` on 2026-11-02: `01` adds `products.customs_value`,
edited by hand; this fills it from the product catalog sync.

## Problem

For goods that are sold, the customs value is the sale price. When there is no order (a
scan-to-add Manual Ship, a replacement), the store's list price is the best stand-in. The
catalog sync already brings in each Product's weight, HS code and origin, but not its
price, so every Product's customs value must be typed in.

## Proposal

- **Shopify:** the variant's `price`, in the shop's currency.
- **Amazon:** the listing's offer price for the marketplace in the Client's currency. The
  listings read asks for `summaries,attributes` (`AmazonListingCatalog`); add `offers`.
- Like the sync's other fields, the store's non-blank value overwrites PolyBag's
  (`ProductCatalogSync`). A Product with no store price keeps what was typed.

## To find out

- **Currency:** fill the value only when the price's currency is the Client's currency.
  Confirm where each source reports it (Shopify `shop.currencyCode`; Amazon per offer).
- **Tax-included prices:** a Shopify store set to include tax in its prices has VAT in the
  variant price, and a customs value excludes VAT. Same question as
  `tax-inclusive-prices/01`. Until it is answered, skip a shop with taxes included.
- **Amazon throttling:** whether `includedData=offers` changes the listings read's cost.
- **Sale prices:** Shopify `price` vs `compareAtPrice`; Amazon's offer may carry a
  discounted price. Which one is the customs value.

## Acceptance criteria

- [ ] A Shopify catalog sync fills customs value from the variant price in the Client's
      currency, and leaves it alone otherwise
- [ ] An Amazon catalog sync does the same from the matching marketplace's offer
- [ ] A store with tax-inclusive prices is skipped until `tax-inclusive-prices/01` is settled
