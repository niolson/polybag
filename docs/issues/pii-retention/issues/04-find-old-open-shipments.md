# Show tenants the open Shipments that have outlived their retention

Status: needs-triage
Category: enhancement
Repo: `polybag`

> *This was generated by AI during triage.*

## Parent

Split out of [`02`](02-purge-skips-company-only-void-and-partly-shipped.md), which decided
that an `open` Shipment is never purged automatically, on any channel. It is still work,
and purging it would break packing. That makes an open Shipment's recipient data the
tenant's responsibility, so the tenant needs a way to see which ones are old.

## Problem

An order that is never shipped and never cancelled stays `open`, with its PII, forever.
Examples: a Database-driver order the source system abandoned, a Shopify order nobody
cancelled, or an order imported for the wrong client. Today the only way to find them is
the Shipments list's `created_at` filter. That filter does not know about the retention
setting, which differs by channel (`pii_retention_days`, globally in App Settings and per
channel).

Once [`03`](03-import-marketplace-cancellations.md) lands, an Amazon Shipment still `open`
past its ship-by date plus seven days should not exist. If one does, it is an exception
worth surfacing, not just an old order.

## Proposed decisions

Each one needs a maintainer to confirm it:

- **A Shipments list filter, "Past retention".** It selects `open` Shipments created longer
  ago than their channel's retention period, the same per-channel setting
  `PurgePiiCommand` uses, falling back to the global one. From there, the tenant edits,
  voids or deletes them with the actions that already exist. A void Shipment is then purged
  under `02`'s rules.
- **A count on `ExceptionsWidget`** linking to that filter, shown only when it is non-zero.
- **Amazon Shipments past ship-by are flagged separately.** An `open` Amazon Shipment more
  than seven days past `metadata.amazon_ship_by_window.latestDateTime` is counted on the
  widget as its own line, because it means a cancellation was missed, not that work was
  forgotten.
- **No automatic action.** Neither the filter nor the widget changes a Shipment.

## Acceptance criteria

- [ ] The "Past retention" filter selects `open` Shipments older than their channel's
      retention period, using the global setting when the channel has none
- [ ] It never selects `shipped` or `void` Shipments
- [ ] `ExceptionsWidget` shows the count and links to the filtered list when it is non-zero
- [ ] An `open` Amazon Shipment past its ship-by date plus seven days is counted separately
- [ ] The filter combines with the list's existing client, location and channel filters

## Out of scope

- Purging `open` Shipments automatically. `02` decided against it
- Importing cancellations: [`03`](03-import-marketplace-cancellations.md)
